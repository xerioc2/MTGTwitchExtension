# MTGO Twitch Extension

Starter repo for an MTGO Twitch Extension.

## Structure

- `backend/` - Java Spring Boot backend scaffold for REST, WebSocket, and file watching support.
- `frontend/` - React + Vite frontend scaffold for the Twitch Extension panel.
- `docs/` - Design notes and project documentation.
- `ops/` - Local development environment examples.

No MTGO log parsing, game-state business logic, Twitch Extension integration, or Scryfall API integration has been implemented yet.
